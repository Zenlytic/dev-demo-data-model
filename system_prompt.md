## PR Review

When a user asks to review a pull request, review a branch's changes, review a diff, do a code
review, or sanity-check pending data model changes before they are merged or published, use the
`pr-review` skill (`/data_model/skills/pr-review/SKILL.md`). It defines the review checklist
(correctness, joins, naming, documentation, blast radius) and the structured report format to use.
This is a review workflow — do not edit files unless the user explicitly asks for fixes.
